# snake-game-
Snake Game in Python
This is a classic Snake Game implemented in Python using the Pygame library. In this game, you control a snake that grows longer as it eats food, while avoiding collisions with the walls and its own tail.

Features
Simple Controls: Use the arrow keys (Up, Down, Left, Right) to control the snake.
Increasing Difficulty: The snake grows longer with each piece of food it eats, making the game progressively more challenging.
Game Over Condition: The game ends when the snake collides with the wall or its own body.
Score Tracking: Your score increases as you eat food. The current score is displayed on the screen.

How to Play
Use the Arrow Keys (Up, Down, Left, Right) to control the snake's movement.
The objective is to eat the food (which is a small square) to make the snake grow longer.
Avoid running into the walls or the snake’s own body.
The game ends if the snake collides with itself or the boundary of the game window.
The score is based on how many pieces of food the snake eats.
Game Controls
Move Up: Up Arrow
Move Down: Down Arrow
Move Left: Left Arrow
Move Right: Right Arrow
